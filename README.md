This simple project is a responsive restaurant website for Світ Сендвіч & Гриль. It displays the restaurant’s image, name, address, menu items, prices, ingredients, and food categories such as shawarma, burgers, hot dogs, and drinks. Users can filter the menu, view meal details, and place an order through the checkout form.

The project uses these languages and technologies:

HTML: Creates the website structure and content.
CSS: Controls the design, colors, layout, images, and responsive appearance.
JavaScript: Displays menu items, filters categories, shows meal details, and handles the checkout form.
Git: Used to manage and upload the project to GitHub.
